### 本机自动化（新功能，默认关闭）

- **设置 → 通用 → 允许本机自动化**：打开后，本机上以你的身份运行的程序（脚本、AI 助手）可以读取和编辑已打开的文档、保存到原路径，切换窗口的模式、侧栏和大小，以及调整 30 个设置（主题、字号、界面语言、编辑器和 Markdown 选项等，立即生效）。只在本机，不经网络；关闭即断开所有连接。
- 有程序连着时窗口标题显示“自动化已连接”，每次改动会短暂显示是哪个程序改了哪个文档；被改的文字会高亮约 2 秒（设置 → 通用 → 高亮程序所做的更改）。
- 每次写入都要带程序读到的版本号：你在它读取后输入的内容不会被旧内容覆盖。可视编辑会丢失内容的正文会被拒绝。
- 安全边界：这个开关信任你这个系统用户下的所有程序，没有逐个程序的授权。说明见 docs/automation.md。
- 安装包新增命令行工具 `typedownctl.exe`（装在安装目录里），`typedownctl mcp` 是给 AI 工具用的 MCP 服务器；说明文档装在安装目录的 `docs` 文件夹。接口 v1 已冻结。

### 修复

- 撤销、重做后，编辑器迟到的一次内容上报可能把刚撤销的内容写回（Windows 与 Linux 共同的页面问题）。
- 源码模式下由程序写入时，只替换改动的部分，光标、选区和滚动位置不再跳动；可视模式只重绘改动的段落。
